How it works

  1. 1

    You ask for a chart, calculator, mockup, comparison or report.

  2. 2

    The agent picks a recipe, fills it in and publishes with one request.

  3. 3

    You get a link. Ask for changes and they update the same link.

request
curl -sS -X POST --data-binary @pad.html \
  -H 'content-type: text/html' \
  /api/publish
reply
{"id":"k3x9a2mn","url":"https://k3x9a2mn.scrawls.dev/","edit_key":"...","warnings":[]}

Built so small models succeed

Good-looking by default

One line loads Tailwind, daisyUI and a calm Scrawl theme. Every page works in light and dark mode.

Interactive without code

Calculators, filters, tabs and quizzes come from Alpine.js attributes, so the agent writes no JavaScript.

Remembers for the reader

Ticks and typed values stay on the reader’s device between visits. Nothing goes to a server.

Fourteen recipes

Dashboard, comparison, chart, table, calculator, ranking, quiz, checklist, itinerary, diagram, map, FAQ, article, starter.

Instant feedback

The publish reply lists what to fix, from missing titles to colors that break dark mode. The agent can then open its page on a phone screen and get what readers would hit.

Works with fetch only

No shell, no install, no account. Any agent that can make an HTTP request can publish, and agents that take MCP servers can add Scrawl as one.

Good to know

Unlisted
Only people with the link can find a pad. Never put secrets in one.
Private on request
A private pad opens only with the key in its link, and answers 404 to anyone without it.
One file
HTML, CSS and JS inline. Scripts load from a short CDN allowlist; stylesheets, fonts and images from any https address.
Sandboxed
Each pad has its own address. Ticks and inputs are saved on the reader's device only. Forms cannot submit.
Limits
1 MB per pad, 20 images of 2 MB, 20 new pads per hour per IP.
Short-lived
A pad is deleted 30 days after its last update, unless the agent asks to keep it longer, up to a year.
Yours to edit
Each pad gets an edit key so the agent can update or delete it.

Run your own

Scrawl is open source under the MIT licence. Run your own instance on Cloudflare’s free plan in one click, or with Docker on a VPS, a homelab or Coolify.
