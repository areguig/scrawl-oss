Git workflow · branch to production

Nothing reaches production without review and green tests

Follow the arrows from the first push to the live release. Two checks can send the change back to the author.

From branch to production

flowchart TD
  A[Push feature branch] --> B[Open pull request]
  B --> C{CI tests pass?}
  C -->|No| F[Author fixes code]
  F --> B
  C -->|Yes| D{Review approved?}
  D -->|Changes requested| F
  D -->|Approved| E[Merge to main]
  E --> G[Deploy to staging]
  G --> H[Deploy to production]
Source: a typical team workflow, simplified for this page, October 2026.
