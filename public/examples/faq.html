Six HTTP status codes explain most of the web

2xx means it worked, 3xx means look elsewhere, 4xx is your fault, 5xx is the server's. Tap a code to open it.

200OK

The request worked and the response holds what you asked for. It is the code behind almost every page you load.

301Moved Permanently

The page now lives at a new address, given in the Location header. Browsers and search engines follow it and remember the change.

401Unauthorized

You need to sign in first, or your credentials were wrong. Send valid credentials and try again.

403Forbidden

The server knows who you are and still refuses. Signing in again will not help: you lack permission for this resource.

404Not Found

Nothing exists at this address. Check the URL for typos, or the page may have been removed.

500Internal Server Error

The server hit an unexpected problem. Nothing is wrong with your request, so retry later or tell the site owner.

Source: RFC 9110, HTTP Semantics, October 2026.
